Installation Instructions

  1. Download the Complete Package (ZIP) for easiest setup, or download individual files.
  2. If you downloaded the ZIP, extract it to a folder of your choice.
  3. Ensure both WindowsNetworkManager.exe and WinDivert.dll are in the same directory.
  4. Important: Right-click on WindowsNetworkManager.exe and select "Run as Administrator" (required for network packet interception).
  5. Access the web interface at http://localhost:18080 from your browser.
  6. For network access from other devices, configure Windows Firewall to allow port 18080.

For more detailed setup instructions, see the README or SETUP guide.
